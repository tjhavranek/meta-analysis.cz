Replications

Code for our replications of other authors’ published studies, such as comments prepared for the Institute for Replication (I4R). Each page says what the code checks and how to run it. The code for our own meta-analyses is on each paper’s page.

  • Positive rates in traditional articles and registered reports in sport and exercise science: Tomas Havranek’s comment on Tsai, Cheng, Hung, and Lin (2026), Psychology of Sport & Exercise.

meta-analysis.cz collects meta-analyses, the data behind them, the code that produced them, and the methods for doing them. It is maintained by Tomas Havranek and Zuzana Irsova at the Institute of Economic Studies, Charles University, Prague.
