These defects are present in the files published here and in the archived deposit. Each will be fixed in the next release. Nothing else in the table is affected.

  • pub_year is not a publication year in alphas, beauty, discrate, skill, students. Those source files carry a standardised regressor of the same name, and the column was matched by name rather than by value. Do not use pub_year for these literatures; every other column is unaffected.
  • remittances reports the source file's raw regression coefficients rather than the partial correlations its paper analyses. Those coefficients run over five different dependent variables, so they are not comparable with each other or with the other literatures. Treat this literature as unusable for now.
  • price_puzzle repeats every estimate 7 times: 7,420 rows where 1,060 are distinct. The source file is already long on horizon while its response columns are wide, and the reshape did not deduplicate. A weighted average is unchanged, but any count of estimates, any unweighted statistic and any method treating rows as independent observations will be wrong for this literature.
